# 图 2：相平面图 (Phase Portrait)

## 数据

复用图 1 的单点平衡数据 `corner_run1.csv`（BAUTO 接管后 25.4 s，`Bal=3` 段）。

- 横轴：倾角误差 `θ = 实际角 − 目标角`（Pitch 目标 23.44°，Roll 目标 50.00°）
- 纵轴：校准后角速度（Pitch 用 `Wx`，Roll 用 `Wy`），单位 °/s
- 两个子图：Pitch 相平面、Roll 相平面
- 展示：时间着色彩色散点（全部 25.4 s）+ 前 8 s 平滑轨迹与方向箭头 + 1σ 稳定包络椭圆

## 结果

| 轴 | 最大 \|θ\| | 最大 \|ω\| | RMS θ | RMS ω |
|----|-----------|-----------|-------|-------|
| Pitch | 0.82° | 8.9 °/s | 0.32° | 1.59 °/s |
| Roll | 0.82° | 9.0 °/s | 0.20° | 1.99 °/s |

相轨迹始终被限制在原点附近的 1σ 包络内，没有出现极限环扩张或发散趋势；
角速度的较高 RMS 主要来自 IMU 噪声与机体高频振动，而非低频不稳定模态。
