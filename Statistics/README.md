# Statistics 实验数据与脚本

所有实验产物（原始数据、采集脚本、MATLAB 绘图脚本、图片、说明）均按实验分类存放。

| 路径 | 内容 |
|------|------|
| `01_闭环平衡时序图/` | 单点平衡 25.4 s：姿态角/角速度/飞轮转速时序，采集脚本、MATLAB 脚本、图 |
| `02_相平面图/` | Pitch/Roll 相平面（偏差 vs 角速度），含早期轨迹、1σ 包络，MATLAB 脚本、图 |
| `03_姿态角与飞轮转速关联图/` | 姿态偏差/飞轮转速/控制电压共享时间轴，含电压→轮速互相关与滞后，MATLAB 脚本、图 |
| `04_PID控制输出与姿态误差/` | 30.25 s 平衡的控制误差/P/D/轮速反馈/总输出电压拆分，含饱和与噪声分析 |
| `05_扰动恢复能力测试/` | 三次人工轻敲扰动恢复：最大偏移 2.9–3.9°、恢复 1.9–2.7 s、振荡 3–4 次 |
| `06_平衡性能指标对比/` | 基线 80/5、低增益 60/4、高增益 110/7 三组 30 s 平衡对比（RMS/最大偏差/恢复/轮速/电压） |
| `07_电机转速阶跃响应/` | 三电机 0%→30%→60%→100%→60%→30%→0% 多级转速阶跃：数据、串口命令序列、MATLAB/Python 脚本、静态图与动画 |
| `08_IMU校准/` | IMU 校准前后各 30 s 的 Yaw 漂移叠加对比：两段数据、自动采集脚本、MATLAB 脚本、静态图与动画 |
| `img/` | 六张参考图（只参考曲线样式） |
| `tools/scope_client.py` | 通用串口采集客户端（PING 保活 + `$TELE` 遥测记录为 CSV） |

设备链路：COM10 @ 115200 8N1（固件 `DEBUG_LINK_USART=2`，USART2），
ST-Link 烧录/复位使用 SN `190A071F7116303030303032`。

> **重要（2026-10-24）：固定 `BREF` 有约 1.3° 的重心偏置。** 单点平衡前必须在
> `BREF` 之后、`BAUTO` 之前发送
> `BNEUTRAL 1 0.00025 0.5 5 23.40 48.60`，否则飞轮会持续加速补偿固定偏差，
> 约 3 s 即电压饱和跌倒。入位以 **PG8 常亮** 为准（参考 Rol≈48.6°，不是 50.0°）。
> 01/04 的采集脚本是在发现该问题前写的，复现时需手动补发这条命令。

各实验文件夹内的 `README.md` 包含实验流程、结果指标与复现命令。
