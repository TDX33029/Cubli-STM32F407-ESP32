# 图 4：PID/LQR 控制输出与姿态误差

## 目标

把平衡时 LQR 的控制输出拆开，观察姿态误差、P 项、D 项、轮速反馈项各自多大，
以及是否存在电压饱和、积分饱和和噪声放大。

## 固件改动（已完成）

控制律本身未改，只在 `$TELE` 中增加每只电机的控制分量（观测用）：

| 字段 | 含义 | 单位 |
|------|------|------|
| `E1–E3` | 控制误差 `err[axis]`（绕各 body 轴的参考误差，含 `theta_0` 配平） | ° |
| `P1–P3` | `BDIR · K_theta · e`，比例项 | V |
| `D1–D3` | `BDIR · K_dtheta · rate`，阻尼项 | V |
| `W1–W3` | `-wheel_weight · (K_w·ω + K_i·∫ω)`，轮速反馈/动量项 | V |
| `U1–U3` | 总输出电压（已限幅） | V |

关系：`U_i = P_i + D_i + W_i + 残差`。残差包含偏航阻尼、corner 轮系耦合与
`BTRIM` 姿态配平项（本实验 `BTRIM 0`，残差应很小）。

> 注意：
> 1. 本配置 `BDIR -1 -1 -1`，所以 `P/D` 与几何误差 `E` 反号，这是控制方向，不是错误。
> 2. LQR 配置 `K_i = 0`、`BTRIM 0`，**没有姿态积分器**，因此不存在经典 PID 的
>    积分饱和；`W` 是轮速反馈（动量项），不是误差积分。
> 3. 电压限幅 6 V，`U` 达到 ±6 V 才算饱和。

## 实验配置

与图 1 相同（`capture_control.py` 自动下发）：

| 项目 | 配置 |
|------|------|
| 模式 | `BMODE 4`，`BAXIS 2 3 1`，`BDIR -1 -1 -1` |
| LQR | `LQR1/2/3 80 5 -0.030 0` |
| 限压/速度 | `U=BU=6 V`，`L=330 rad/s`，`BFULL 250 rad/s` |
| 保护 | `BTRIP 20°`，`BCAP 0.5°` |
| 启动 | `BAUTO 1 2` |

> 2026-10-24 补充：本机固定 `BREF` 有约 1.3° 重心偏置。复现时应在 `BREF` 后、
> `BAUTO` 前发送 `BNEUTRAL 1 0.00025 0.5 5 23.40 48.60`，并以 **PG8 常亮** 入位；
> 否则飞轮约 3 s 饱和。详见 05/06 的 README。

## 现场步骤

1. 设备**平放**在桌面并保持静止（不要用手扶，等对齐和 IMU 校准完成）。
2. 运行采集：

   ```bash
   py capture_control.py COM10 ctrl_run1.csv --seconds=60
   ```

3. 脚本自动完成三轴对齐（约 20 s）和 `CAL_IMU`，然后提示把设备扶成单点姿态
   `Pit≈23.4° / Rol≈50.0°` 并保持约 12 s。
4. PG8 常亮表示进入 0.5° 入位窗口；PG5 倒计时 2 s；**PG6 亮起时松手**。
5. 采集 60 s 后脚本发 `STOP`，设备退出平衡；数据写入 `ctrl_run1.csv`。

## 图的构成

五个子图共享时间轴（以自动接管时刻为 0）：

| 子图 | 内容 |
|------|------|
| (a) | 控制误差 `E1/E2/E3` |
| (b) | P 项 `P1/P2/P3` |
| (c) | D 项 `D1/D2/D3` |
| (d) | 轮速反馈项 `W1/W2/W3` |
| (e) | 总输出 `U1/U2/U3` + ±6 V 限幅线 |

每个子图标题给出 RMS/占比/相关系数/噪声等指标，控制台同时打印完整数值。

## 指标定义

| 指标 | 定义 |
|------|------|
| 高频噪声 | 信号减去 0.45 s 滑动平均后的标准差（°或 V） |
| 分量占比 | `mean(|P|) : mean(|D|) : mean(|W|)` |
| 饱和占比 | `|U| ≥ 0.995·6 V` 的采样比例 |
| 重构残差 | `U − P − D − W` 的 RMS/最大值 |

## 结果

`ctrl_run1.csv`：30.25 s 连续平衡（606 帧，平均 50 ms），无跌倒、无电压饱和。

| 指标 | M1 | M2 | M3 |
|------|----|----|----|
| 控制误差 RMS | 0.37° | 0.32° | 0.41° |
| 控制误差峰值 | 0.94° | 1.11° | 1.14° |
| 误差高频噪声 | 0.17° | 0.24° | 0.20° |
| P 项 RMS | 0.51 V | 0.44 V | 0.57 V |
| D 项 RMS | 0.20 V | 0.22 V | 0.21 V |
| W 项 RMS | 2.55 V | 1.89 V | 2.75 V |
| 总输出 RMS | 2.09 V | 1.56 V | 2.43 V |

| 汇总指标 | 数值 |
|----------|------|
| 分量占比 `|P| : |D| : |W|` | 15% : 6% : 80% |
| 总输出峰值 / 限幅 | 3.66 V / 6 V（未饱和） |
| 饱和占比 | 0.0% |
| 重构残差 `U−P−D−W` | RMS 0.152 V，最大 0.517 V |
| 同点相关 | `corr(e,P)=−1.00`，`corr(e,D)=0.40`，`corr(e,W)=0.34` |
| 轮速终值 / 峰值 | −73 / −89 / −105 rad/s；峰值 126 rad/s |

## 解读

1. **输出由轮速反馈（动量项）主导。** `W` 占 80%，P 项只占 15%，D 项 6%。姿态 PD
   是在一个很大的轮速反馈基座上做小修正；这也解释了为什么 LQR 的 `K_w` 符号和
   轮速方向必须与电机接线一起验证，单看电压符号容易误判。
2. **P 项与误差严格反号。** `corr(e,P)=−1.00` 是 `BDIR -1 -1 -1` 的直接结果：
   几何误差为正时，施加电压为负。这是方向配置，不是异常。
3. **没有积分饱和。** `K_i=0`、`BTRIM 0`，控制器没有姿态积分器；`W` 中的
   `K_i∫ω` 也为零，所以不存在经典 PID 的积分饱和问题。轮速反馈本身是比例项，
   不是误差积分。
4. **没有电压饱和。** 峰值 3.66 V，距 6 V 限幅仍有约 39% 余量；30 s 内轮速虽
   然升到 −126 rad/s，但控制输出没有触顶。
5. **噪声水平低。** 误差高频成分 0.17–0.24°，输出高频成分 0.24–0.33 V，主要来自
   编码器 0.1 rad/s 量化与 IMU 噪声，没有看到明显的高频抖振。
6. **残差不可忽略但不大。** `U−P−D−W` 最大 0.52 V，对应偏航阻尼、corner 三轴
   耦合项与 `BTRIM`（本实验为 0）；说明五分量拆分覆盖了输出的大部分。

> 采集注意：第一次尝试在 PG6 亮起后仍扶着设备，飞轮在机体被约束的状态下空转到
> −216 rad/s，12 s 后饱和跌倒，数据未采用。第二次在 PG6 亮起瞬间松手，得到上述
> 30 s 干净数据。复现时务必在 PG6 亮起时立即松手。

## 复现

```bash
py capture_control.py COM10 ctrl_run1.csv --seconds=60
# 或设备已校准、只想重扶姿态时：
py capture_control_wait.py COM10 ctrl_run1.csv --balance=30 --wait=600
matlab -batch "cd('<本目录>'); plot_control_components"
```
