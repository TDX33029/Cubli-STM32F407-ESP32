# 图 5：扰动恢复能力测试

## 目标

在单点平衡过程中施加三次可重复的人工轻敲，测量最大偏移、恢复时间和二次振荡次数，
检验 LQR 的扰动抑制能力。

## 关键前提：中性参考必须启用并种子

这台设备存在约 1.3–1.8° 的固定重心偏置：固定 `BREF`（Rol=50.00°）并不是真实平衡点。
历史中性搜索结果（`Diagnostics/2026-10-18`）为：

| 试验 | `NPit` | `NRol` | 偏移 |
|------|--------|--------|------|
| 60 s | 23.36° | 49.05° | 0.877° |
| 120 s | 23.49° | 48.20° | 1.649° |

若不启用中性搜索，控制器会持续给飞轮加速来补偿这 1–2° 的常值偏差，约 3 s 即
电压饱和跌倒。本实验在 `BREF` 之后、`BAUTO` 之前执行：

```
BNEUTRAL 1 0.00025 0.5 5 23.40 48.60
```

即启用中性参考搜索（增益 0.00025、最大 0.5°/s、范围 ±5°），并把参考种子到
`Pit 23.40° / Rol 48.60°`。之后设备实际在 `Pit≈23.3° / Rol≈49.2°` 附近平衡，
平衡中搜索继续缓慢收敛。

> `BREF` 会调用 `LQR_ResetNeutralLearning()` 清除中性学习，所以顺序必须是
> `BREF → BNEUTRAL → BAUTO`。

## 实验与数据

| 项目 | 配置 |
|------|------|
| 数据 | `kick_run1.csv`，`Bal=3` 段 30.19 s，605 帧 |
| 模式 | `BMODE 4`，`BAXIS 2 3 1`，`BDIR -1 -1 -1` |
| LQR | `LQR1/2/3 80 5 -0.030 0` |
| 限压/速度 | `U=BU=6 V`，`L=330 rad/s`，`BFULL 250 rad/s` |
| 中性参考 | `BNEUTRAL 1 0.00025 0.5 5 23.40 48.60` |
| 扰动 | 人工轻敲 3 次，约 2.6 / 7.9 / 12.9 s |

现场操作：扶到 **PG8 常亮**（不要按旧的 Rol 50° 找），PG6 亮起瞬间松手；松手后
15 s 内轻敲三次，同一侧、力度一致。第一次采集时未敲击（数据无冲击），第二次
采集到三次有效冲击。

## 冲击检测与判据

- 冲击时刻：陀螺角速度模长 `|W|` 首次超过 `max(18°, 4×中位数)` 的时刻；2.5 s
  不应期，避免把响应中的二次角速度峰当作新冲击。
- 最大偏移：冲击后 2.5 s 内姿态偏差模长 `sqrt(ePitch² + eRoll²)` 的最大值（原始值）。
- 恢复时间：平滑后（0.25 s）的偏差回到**冲击前包络**
  `baseline_mean + max(0.25°, 2×baseline_std)` 以下并保持 0.5 s 的时间。
- 二次振荡：恢复前、包络以上的局部极大值个数（0.08° 最小突出度，0.35 s 不应期）。

## 结果

| 指标 | K1 | K2 | K3 |
|------|----|----|----|
| 冲击时刻 | 2.64 s | 7.90 s | 12.92 s |
| 角速度峰值 | 25.0°/s | 35.8°/s | 31.4°/s |
| 最大偏移 | 2.93° | 3.91° | 3.88° |
| 峰值出现时间 | 0.55 s | 0.09 s | 0.85 s |
| 恢复时间 | 2.69 s | 1.91 s | 2.46 s |
| 二次振荡 | 4 次 | 3 次 | 3 次 |
| 控制电压峰值 | 4.51 V | 5.88 V | 6.00 V |

整段：平衡保持 **30.19 s**，无跌倒；轮速峰值 201 rad/s（低于 `BFULL 250`）；
中性参考在 30 s 内从 `22.92/48.69°` 缓慢收敛到 `23.31/49.18°`。

## 解读

1. **三次冲击都能恢复，未跌倒。** 最大偏移 2.9–3.9°，恢复 1.9–2.7 s，二次振荡
   3–4 次，量级一致，说明在该强度下恢复行为可重复。
2. **K2 的响应最快、偏移最大。** 角速度峰值 35.8°/s，偏差在 0.09 s 达到 3.91°，
   1.91 s 恢复；K1/K3 的偏差峰值滞后 0.5–0.9 s，恢复略慢。敲击方向和接触刚度
   不同会造成这种差异，属于人工扰动的固有离散性。
3. **K3 的控制电压达到 6 V 限幅。** K2 也已到 5.88 V，说明这类 3–4° 扰动已经
   接近当前 `U=6 V` 的权限边界；更重的敲击可能无法恢复。若需要更强抗扰，应提高
   电压上限或降低重心偏置，而不是继续加大 LQR 增益。
4. **轮速峰值 201 rad/s**，距 `BFULL 250` 还有约 20% 余量；多次连续冲击会快速
   消耗轮速余量，实际使用中需要留出恢复间隔。
5. **中性参考仍在缓慢移动**（30 s 内 Roll +0.49°），说明固定参考偏置尚未完全
   收敛；长时间平衡时它会继续逼近真实重心位置。

## 文件

| 文件 | 说明 |
|------|------|
| `kick_run1.csv` | 原始遥测（30.19 s 平衡 + 三次冲击） |
| `capture_seeded.py` | 使用已种子中性参考，等待入位并记录 30 s |
| `capture_disturbance.py` | 完整准备版（对齐/校准/配置/种子/等待/记录） |
| `plot_disturbance.m` | 冲击检测、指标计算、三联图 |
| `disturbance_recovery.png` | 输出图 |

## 复现

```bash
# 设备已校准、中性参考已种子:
py capture_seeded.py COM10 kick_run1.csv --balance=30 --wait=600
# 换电池/复位后从头开始:
py capture_disturbance.py COM10 kick_run1.csv --prepare --balance=30 --wait=600
matlab -batch "cd('<本目录>'); plot_disturbance"
```

现场以 **PG8 常亮** 为准入位，PG6 亮起瞬间松手；松手后约 4/9/14 s 各轻敲一次。
