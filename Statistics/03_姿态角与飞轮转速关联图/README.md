# 图 3：姿态角与飞轮转速关联图

## 目标

在同一时间轴上展示平衡过程中姿态偏差与三只飞轮转速/控制电压的关系，回答两个问题：

1. 姿态偏离时，飞轮是否及时加减速、方向是否正确？
2. 实际轮速响应相对控制指令滞后多少？

## 实验与数据

直接复用图 1 的同一段单点（corner）平衡数据，无需重新采集：

| 项目 | 配置 |
|------|------|
| 数据 | `corner_run1.csv`（复制自 `01_闭环平衡时序图/`） |
| 模式 | `BMODE 4`，`BAXIS 2 3 1`，`BDIR -1 -1 -1` |
| LQR | `LQR1/2/3 80 5 -0.030 0` |
| 限压/速度上限 | `U=BU=6 V`，`L=330 rad/s`，`BFULL 250 rad/s` |
| 平衡段 | `Bal=3`，25.38 s，508 帧，平均采样 50 ms |

> **重要说明：单点平衡没有转速目标。** 平衡时 `M1/M2/M3 = 0`，LQR 直接输出
> 三相电压 `U1–U3` 驱动飞轮，因此图中把**控制电压**作为等效指令，而不是
> `M1–M3` 目标转速（若画 M1–M3 会得到三条 0 线）。

## 图的构成

三个子图共享时间轴（以自动接管时刻为 0）：

| 子图 | 内容 |
|------|------|
| (a) | 姿态角偏差 `Pit−RefPit`、`Rol−RefRol` |
| (b) | 飞轮实际转速 `S1/S2/S3` |
| (c) | LQR 控制电压 `U1/U2/U3` |

## 结果

| 指标 | 数值 |
|------|------|
| 姿态偏差 RMS | Pitch 0.32°，Roll 0.20° |
| 姿态偏差峰峰 | Pitch 1.44°，Roll 1.34° |
| 轮速终值 | S1 −38.1，S2 −62.3，S3 −62.3 rad/s |
| 轮速峰值 / 余量 | 65 rad/s，距 `BFULL 250` 余量 74% |
| 轮速平均斜率 | −0.73 / −1.06 / −1.01 rad/s² |
| 控制电压均值 | −0.72 / −1.04 / −1.26 V（范围 −2.07…0.40 V） |
| 电压→轮速互相关峰值 | 0.80 / 0.85 / 0.89 |
| 电压→轮速表观滞后 | 0.15 / 0.10 / 0.10 s |

姿态偏差与**轮速变化率**的相关系数（负号表示姿态偏向正方向时飞轮向负方向加速）：

| 轮 | corr(Pitch 偏差, dS) | corr(Roll 偏差, dS) |
|----|----------------------|---------------------|
| S1 | −0.26 | −0.77 |
| S2 | −0.59 | +0.04 |
| S3 | −0.74 | −0.48 |

## 解读

1. **飞轮方向正确、响应及时。** 姿态偏差与轮速变化率反号：Pitch 偏正时 S2/S3
   向负方向加速（r = −0.59 / −0.74），Roll 偏正时 S1 向负方向加速（r = −0.77）。
   轮系分工也与 corner 布置一致：S1 主要响应 Roll，S2/S3 主要响应 Pitch。
2. **轮速主要被恒定重力矩负载支配。** 单点平衡时重力矩恒定，飞轮必须持续反向
   加速提供反作用力矩：25 s 内从 0 漂移到 −38/−62/−62 rad/s，平均 −0.73…−1.06
   rad/s²，全程远未饱和。姿态偏差只有 ±0.8°，因此"姿态角—绝对轮速"的直接相关
   性弱是正常的；关联体现在**轮速变化率**上，而不是轮速绝对值上。
3. **表观滞后约 0.1 s，但不是纯执行器延迟。** 电压与轮速互相关 0.80–0.89，峰值
   出现在轮速滞后 0.10–0.15 s（2–3 个采样）。注意这是**闭环互相关**：`U` 本身
   包含轮速反馈项，且 `U` 同时补偿反电动势与摩擦，因此该数值只能作为表观滞后
   的上界，不能解释为纯电机/驱动器延迟。受 50 ms 采样和 0.1 rad/s 编码器量化
   限制，无法从这组数据进一步分离更小的延迟。
4. **没有转速饱和风险。** 25 s 平衡内轮速峰值 65 rad/s，距 `BFULL 250` 仍有 74%
   余量；按当前斜率，单次平衡可持续约 3–4 min 才会触及轮速上限。

## 文件

| 文件 | 说明 |
|------|------|
| `corner_run1.csv` | 原始遥测（与图 1 同一段） |
| `plot_attitude_wheel.m` | MATLAB 绘图 + 相关性/滞后计算脚本 |
| `attitude_wheel.png` | 输出图 |

## 复现

```bash
matlab -batch "cd('<本目录>'); plot_attitude_wheel"
```

脚本自动完成：`$TELE` 解析 → 提取 `Bal=3` 段 → 计算 RMS/峰峰/轮速斜率/电压统计
→ 重采样 50 ms 做互相关 → 输出 PNG 与控制台指标。
