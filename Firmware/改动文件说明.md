# Cubli-F407ZGT6 工程审查与 LQR 平衡控制算法修复说明

## 一、工程审查与算法分析结论

### 1. 原工程中的平衡算法是否为 LQR？
**结论：不是 LQR，原工程此前完全没有实现机体平衡控制算法。**
- **实际代码现状**：
  原工程仅包含了底层无刷电机 FOC 矢量驱动（基于 SimpleFOC 改编），实现了电机的开环调速（`Type_velocity_openloop`）和速度闭环调速（`Type_velocity`，基于速度误差的 PID 运算）。
- **平衡控制算法完成度**：
  **0%（完全缺失）**。虽然板载了六轴姿态传感器（LSM6DSRTR SPI2 与 MPU-6050 软 I2C），但此前仅用于在串口中以 25Hz 打印原始数据，既没有进行机身姿态解算（如卡尔曼滤波、互补滤波），也没有将机体倾角和动量轮转速引入闭环反馈，更没有任何边沿平衡（1D Edge Balance）或顶点平衡（3D Corner Balance）控制律。

## 二、修复与新增算法架构 (基于 ETH Zurich 原版 Cubli 模型)

参考瑞士苏黎世联邦理工学院 (ETH Zurich) 动量轮平衡机器人 (The Cubli) 的经典控制理论，针对本项目进行了完整的姿态估计与 LQR 平衡控制算法实现：

### 1. 姿态估计与滤波解算 (Attitude Estimator)
- **多传感器融合一阶卡尔曼滤波器**：
  结合机载加速度计（计算静态重力倾角）与三轴陀螺仪（积分角速度动态量），实时解算立方体机身在空间中的绝对倾角（Pitch 与 Roll）和三轴真实角速度。
- **陀螺仪静态零偏自动标定**：
  通过 `CAL_IMU` 指令采集 200 个样本并计算三轴陀螺仪漂移零偏，扣除零偏后消除长积分发散。

### 2. 1D 边沿平衡 4 态 LQR 控制器 (1D Edge Balancing LQR)
- **状态向量定义**：
  $$x = \begin{bmatrix} \theta - \theta_0 \\ \dot{\theta} \\ \omega_w \\ \int \omega_w \, dt \end{bmatrix}$$
  其中：
  - $\theta - \theta_0$：机体偏离平衡竖直点偏差角 (rad)；
  - $\dot{\theta}$：机体绕支承边的倾斜角速度 (rad/s)；
  - $\omega_w$：对应动量轮相对于机体的机械旋转角速度 (rad/s，由 MT6701 磁编码器测出)；
  - $\int \omega_w \, dt$：动量轮转速积分量 (rad)，用于彻底消除因机械加工偏心或重心不对称产生的稳态飞轮残余高速旋转（退饱和作用）。
- **LQR 反馈控制律 (电压域相电压输出)**：
  $$u = K_p (\theta - \theta_0) + K_d \dot{\theta} + K_w \omega_w + K_i \int \omega_w \, dt$$
  输出限幅在相电压安全范围内（默认 $\pm 6.0\text{V}$）。

### 3. 3D 顶点平衡解耦 LQR 控制器 (3D Corner Balancing LQR)
- 顶点朝下平衡时，机身空间对角线垂直向上。
- 将三台正交安装的动量轮沿空间对角线正交平面进行 $120^\circ$ 几何解耦，映射为两个独立的水平虚拟倾角轴和一个偏航轴。
- 分别运行双轴 LQR 算法计算虚拟恢复力矩，加入偏航角速度阻尼 $T_z = -K_{yaw} \omega_z$，最后经由坐标逆变换矩阵分配到三台无刷电机相电压。

### 4. 跌倒安全保护状态机 (Fall Detection & Safe Disarm)
- 状态机包含：`DISABLED`（失能）、`CALIBRATING`（零偏校准）、`STANDBY`（就绪捕获）、`BALANCING`（闭环平衡中）、`FALL_PROTECT`（跌倒保护）。
- 当机身倾角偏差超过阈值（默认 $15^\circ$）时，立即触发跌倒保护，瞬间切断 PWM 相电压并清空转速积分，避免电机在倒地后飞车或堵转烧毁。
- 当机身回到平衡捕捉窗口（$5^\circ$ 内）后，自动恢复闭环平衡。
