## 4. 数学路线及未完成部分

以几何中心为原点，以三个电机面朝外的法向e1/e2/e3定义位置投影坐标。此顺序不保证右手系，叉乘动力学需使用正确映射后的IMU坐标；静态距离/直线投影不受该顺序影响。

用户描述的名义支撑点：

```text
P = (35, 35, -35) mm
C = Σ(mi * ci) / Σmi
r = C - P
```

固件的 `attitude.gravity` 实际上是归一化加速度计方向，静止时指向竖直上方。角点零重力矩姿态选择重心在支撑点上方：

```text
g_ref_IMU = B * (C - P) / |C - P|
B = [M1面外法向_IMU, M2面外法向_IMU, M3面外法向_IMU]
Pitch = atan2(gy, sqrt(gx² + gz²))
Roll  = atan2(-gx, gz)
```

如果重心恰在几何中心，位置投影参考为 `(-1,-1,+1)/sqrt(3)`，主板法向与竖直夹角约54.7356°。**这只是均匀几何例，不是当前Cubli的实测参考。** 三套相同重轮安装在三个面上不会自动让重心落到几何中心，主板和外置电池也会移动重心。

### 可行方法优先级

**A. 如果以后可以从实际支撑角悬挂：一次静态测量直接求姿态。**

```text
同一个物理点P悬挂：C = P - λ * g_up_hang
该点作为下方支点平衡：g_ref = -g_up_hang
```

只求角度不需要称重、重心高度或三电机面符号。必须是实际支撑点；系点若有偏移，不能直接取反当成精确参考。该简化关系已推导写入说明，**还没有集成到工具，也没有真实悬挂数据**。

**B. 已知两个以上挂点：求完整重心坐标。**

每次自由静态悬挂满足 `C = Pi - λi * g_up_i`。两条不平行重力线可解C，三次以上可检查误差。离线工具 `diagnostics/corner_com_geometry.py` 已实现最小二乘交点、近乎平行拒绝、残差和重心位于挂点下方的检查；不打开串口。七项合成几何检查通过，仅证明数学实现，没有真实COM结果。

现有输入/输出：`diagnostics/2026-10-15/corner_com_geometry_inputs.json`、`corner_com_geometry_result.json`、`corner_com_geometry_verification.json`。输入中签名面法向仍为null、悬挂观测为空，当前结果明确 `actual_com_reference_available=false`。

**C. 用户暂时无法悬挂：选择可执行的替代测量。**

可考虑测量组件质量和实际重心位置，或通过已知支点/多次支撑称重识别整机重心。设计方法时明确可观测量、支点坐标和误差；不要用未经测量的电机质量、手扶力最小的位置、软桌面站立或有持续飞轮加速时的平均姿态替代重心数据。

### 我原本准备继续做的代码工作

1. 为离线工具补充同角悬挂取反入口，明确“只识别参考方向”与“已求得三维重心坐标”的差别；保留未验证标记。
2. 完善静态数据提取：逐样本重建/平均归一化重力向量，检查姿态散布、角速度、飞轮静止与全程失能。不要直接平均可能跨±180°或接近Pitch±90°的Euler角。
3. 只接受可复核的静态测量，输出候选参考、置信/误差指标和来源文件；不自动改上位机默认值、不自动启动电机。
4. 测量方法可行且数据满足条件后，再做候选参考的有界实机验证。

零重力矩姿态仍是倒立摆的开环不稳定平衡点。正确参考是必要步骤，不能替代控制器稳定性与可用力矩分析。

## 7. 动态模型：哪些结论已经撤回

`diagnostics/corner_loop_model.py` 的旧实现存在重力坐标项、内部反作用力处理、按最稳定极点反推轮轴符号等问题，增益推荐已撤下；当前命令打印说明并返回2，这是有意行为。原实现可从Git `f7f7733` 查阅。

`analyze_corner_windup.py --settle` 只输出描述性拟合及实验姿态候选；不能从有持续飞轮加速时的平均姿态证明真实重心，更不能承诺“两三轮必然收敛”。旧−0.05试验同时改过Ki，不能拿来否决Ki=0时的独立Kw对照。−0.040仍只是未执行的候选，数学标定优先。

如需重建动力学，先在统一的IMU右手坐标中定义惯量、轮轴符号和重力方向。例如固定支撑点的角动量方程可写为：

```text
Jp * omega_dot + omega × (Jp*omega + Hwheel) + Hwheel_dot
    = -m*g0 * (C-P) × g_up
Hwheel = N * diag(Jwheel) * wheel_speed_relative
```

其中Jp含锁定轮组随机体转动的惯量；内部电磁/摩擦反作用不能只加在轮上，外部空气阻力需区分；支撑点必须实际固定且无手/线材额外力矩。符号来自实测，不能根据希望得到稳定极点而选择。正确的静态参考也不自动保证闭环稳定。
