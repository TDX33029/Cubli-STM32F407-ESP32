# 三轴单点调试

当前基线是2026-10-18融合有界自动寻点的参数组（80/5/−0.04/0、BYAW6、τ0.25、BCAP1、BNEUTRAL寻点5°），已完成带监护的8/15/60/120秒限时运行，最长一轮120秒无触发保护（记录见 `../diagnostics/2026-10-18/neutral5_plane_resume_trial*`）。长期无人值守自由平衡尚未验证。2026-10-15后续自动模式保留，审阅说明见 `../接手审阅_2026-10-15.md`。旧自述文件属于历史记录，其中模型推荐及参考收敛结论已撤回。

## 参数与准备

映射：M1→IMU Y、M2→IMU Z、M3→IMU X（BAXIS 2 3 1），机体方向均−1。电机对应ENC3/ENC1/ENC2、7极对、编码器方向+1；机体方向与编码器方向是不同参数。每次掉电/烧录后重新自检，不能把启动占位映射当成识别结果。供电仍按原12V配置。

把机体放稳，三只飞轮不接触桌面、线材或其他物体，然后执行三轴自检/对齐、静止IMU校准。校准只估计陀螺仪零偏，无需水平，但必须静止。重新自检会清除对应方向/参考确认，需要重新加载配置。

上位机连接当前实际串口（115200），在“平衡控制”中选择顶点（三轴）；上位机会在自检与启动平衡时自动切换固件的调试/工作模式，无需手动切换。待三轴Aligned=111、Cal=1、无故障后，点击“加载已验证单点配置（失能）”。此按钮只配置，不启动电机。配置为：

- 固定参考Pitch=23.4399°、Roll=50°（重力向量−0.702828789/0.397786931/0.589743377）。
- 三轴80/5/−0.04/0，BYAW=6，姿态滤波τ=0.25秒，BTRIM=0，U/BU=6V。
- 自动模式硬轮速L330、满速250rad/s持续3秒、倾倒20°、入位总倾角1°、倒计时2秒。
- 有界自动寻点（默认开启）：`BNEUTRAL 1 0.000075 0.3 5`，目标沿倾斜平面按飞轮轮速修正，总范围5°。

BTRIM在固件、上位机和自动脚本中默认均关闭。旧固件可能默认2，因此加载会明确下发0并要求新状态回读一致。参考是已测试控制目标，不是已证明的重心中性点。电池位置/结构变更后需要重新验证。

## 自动寻点与限时运行

寻点开启后状态帧回读 `NOn/NTune/NPit/NRol/NOff/NLimit/NRate/NGain`，界面“固件寻点”一行显示当前目标与偏移。学习结果在停止（`BAL 0`）后保留；界面上显示“记忆目标”，重新加载配置时若勾选“重载配置时恢复学习目标”，会把最近目标作为seed恢复（超出5°总范围或任一重力分量过小时自动从锚点重新开始）。换模式、重新采集参考或IMU重新校准会清除学习。

“启动限时平衡（到时自动停止）”按钮：扶到1°窗口内，PG5倒计时、PG6亮即松手；接管后计时，界面显示剩余秒数，到时自动 `BAL 0` 失能并保留寻点学习。跌倒/保护停机（Bal=4）或急停会取消计时。首次使用建议15秒起步，确认桌面、线材和监护到位后再延长到60秒以上；120秒记录对应增益0.000075/速率0.3°/秒/范围5°，勿在调参时无人看护运行。

## 自动模式与灯光

点击“启动自动单点（无固定时长）”后，三轴均对齐、传感器/参考有效、总倾角<1°（BCAP）、角速度<0.2rad/s、三轮均<5rad/s，持续1秒后进入2秒倒计时，整个倒计时保持在BCAP窗口内，最后至少0.5秒角速度低于0.2rad/s。PG5闪烁表示倒计时，PG6亮表示实际接管，此时立即松手。离开入位条件会取消倒计时。

总倾角超过20°，或任一轮绝对转速达到250rad/s持续3秒，立即失能并等待下次入位；满速计时在降至阈值以下时清零。重试至少等1秒，且须等三轮降至5rad/s以下，再重新满足入位和完整倒计时。超过330rad/s、机体角速度超限、传感器/驱动故障、急停或通信超时会退出自动模式，不自行恢复。点击停止会取消自动重入。

自动模式没有运行时限；这不代表已验证长期稳定，也不应在调参阶段无人看护运行。现场支撑和接住方式须在启动前安排，飞轮与线材不得承重。

## 脚本与记录

重新对齐/校准可用有界准备脚本，tag须唯一（拒绝覆盖同名日志）：

```powershell
python diagnostics/corner_auto_prep.py --port COM7 --tag prep_YYYYMMDD_HHMMSS
```

当前入位条件为2秒/1°（BCAP 1）。先复测限时基线；使用 `diagnostics/serial_corner_trial.py --help` 查看参数，固定参考、U6、主机轮速220rad/s、固件240rad/s、总倾角10°、角速度1.5rad/s。不要把自动模式较宽的阈值当成首轮必需设置。带寻点的复现命令示例（与上位机配置等效；`--expected-pose`为姿态监测采集的静止姿态summary，`--output-dir`决定日志目录）：

```powershell
python diagnostics/serial_corner_trial.py --port COM9 --tag neutral5_trial15s_YYYYMMDD --seconds 15 --wait-seconds 600 ^
  --countdown 2 --capture-angle 1 --voltage 6 --wheel-bound 220 --body-rate-bound 2 ^
  --kp 80 --kd 5 --kw -0.04 -.04 -.04 --yaw-damping 6 --attitude-tau .25 ^
  --body-axes 2 3 1 --directions -1 -1 -1 --expected-pose diagnostics\2026-10-14\repaired_corner_hand_pose_still_summary.json ^
  --reference-gravity -0.7028287890572913 0.3977869310324257 0.5897433770480731 ^
  --neutral-learning --neutral-gain .000075 --neutral-rate .3 --neutral-limit 5 ^
  --output-dir diagnostics\2026-10-18
```

连续多轮时用上一轮summary作为 `--resume-neutral-from`（同次上电保留学习）或 `--seed-neutral-from`（复位后从原锚点恢复）；STOP不清理学习，不要每轮重发BMODE/BAXIS/BDIR/BREF清空学习。

准备充分后，带现场监护的自动模式记录入口为：

```powershell
python diagnostics/serial_corner_auto.py --port COM7 --tag corner_YYYYMMDD_HHMMSS --duration-minutes 1 --live-state live_pose.json
```

省略duration-minutes时无限运行。Ctrl+C或错误退出时STOP、FAST 0、恢复U2.5/L15并确认失能。`--prepare-only`只配置、不启动。`--capture-pose`改为现场BZERO采集，手扶姿态只能算候选。不要同时运行两个占串口的程序。

`analyze_corner_windup.py --settle`输出的姿态均值仅用于实验比较；不能据此声称已识别重心或必然收敛。`corner_loop_model.py`已撤下增益推荐。BTRIM非零仍属实验，默认不启用。

## 实时入位提示

`Software/pose_monitor.py`读取姿态JSON，不占串口；配合脚本 `--live-state` 与窗口 `--live-file` 使用。超过1秒无更新会暂停显示。“记录当前姿态为候选”仅在实时、失能时可用，不会启动电机。提示窗口圆圈与固件配置同步为0.5°，窗口内自动放大显示；倒计时实时显示剩余时间。界面的0,0是目标误差归零，不是机体Euler角为0°。
