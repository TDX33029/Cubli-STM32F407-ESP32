# Cubli 上位机：平衡控制（顶点/单边）

当前版本配套 `../Cubli-ST` 固件，需支持 `$STATE` 状态帧。旧板通过 USART2 (PD5/PD6) 与电脑直连，不需要 ESP32。

上位机界面只保留平衡工作流：左侧为“三轴自检/对齐互锁卡片 + 平衡控制 + 参数配置”，单电机调速、三轴同步、速度环 PID、开/闭环切换等调试面板已移除（2026-10-18 精简，见《界面精简说明_2026-10-18.md》）。调试命令仍可通过右侧终端手动发送。

## 启动与连接

安装 `requirements.txt` 后运行 `python main.py`，或运行 `run_upper_computer.bat`。

串口设置为 115200/8N1，连接 PD5(TX)、PD6(RX)、GND，上位机选择对应串口。切换上位机的链路下拉框不会改变单片机的物理通信口。

上位机每250ms发送一次 `PING`。STM32 超过1500ms未收到心跳时失能电机。自写串口工具也必须持续发送心跳。正常关闭程序/断开连接会发送STOP；无线桥断开客户端也会发送STOP。

## 三轴自检与对齐（平衡前必须完成）

1. 连接后默认所有驱动保持失能。点击“开始三轴自检/对齐”（自检卡片与平衡面板中均可），上位机自动依次对 M1→M2→M3 执行硬件自检：先识别编码器映射，再正反向扫描电周期、核验极对数和静止零位，全程约十余秒，结束后保持失能。
2. 每次仅驱动当前一个电机；单轴失败时该轴显示失败原因（映射/对齐/离线），其余轴继续检测；三轴全部通过后控制功能解锁，可以进行平衡操作。
3. 停止/急停会中止正在进行的检测；重新自检会清除对应方向/参考确认，需要重新加载配置。

自检通过表示映射、正反向跟随与配置极对数核验通过，并完成静止电角度对齐，不代表已完成电流、温升或转速性能测试。电机与编码器的映射由固件自检识别。

## 平衡模式（顶点/单边）

1. 平衡要求当前模式的电机全部对齐（顶点模式要求三轴全部通过三轴自检）；上电/复位后需重新执行。
2. 在“平衡控制”中选择边沿 M1/M2/M3 或顶点（三轴）。上位机自动管理固件的调试/工作模式：自检与对齐自动切到调试模式（APP 0），启动平衡、倒计时和自动平衡自动切到工作模式（APP 1），无需手动切换。
3. 将机体保持静止，点击“静止校准 IMU”。连续200个静止样本完成校准；运动会重置计数。校准结束保持失能。
4. 在“轮轴对应”中核实每个电机对应的IMU X/Y/Z轴，点击确认（BAXIS），再核实并设置机架方向BDIR。默认轴/方向未明确确认时禁止启动。随后扶住机体，将其放在真实边沿/顶点平衡姿态，点击“采集当前平衡姿态”。这是目标重力方向；不能用平放桌面的姿态代替顶点平衡点。
5. 按实际机械安装设置 M1/M2/M3 机架方向，并设置所选平衡模式的各轴增益。参数读取按钮回读当前轴；下发增益、设置方向会先失能。
6. “启动平衡”先等待约3°接管窗口、低角速度保持100ms后才使能；也可使用下述8秒倒计时入位流程。姿态偏差超过配置阈值（当前默认20°）、编码器掉线、IMU失效/过期、驱动故障、超速或持续堵转时停机。跌倒保护不会自动重启，重新扶正后需再次点击启动。
7. “停止平衡”或急停会关闭全部驱动；急停或安全锁存后点击“复位安全停机锁存（保持失能）”可清除锁存。

**坐标约定必须核实**：控制器要求三台轮轴正交，并用BAXIS明确各轮轴对应IMU X/Y/Z；初始X/Y/Z只是待确认的默认值。机架方向 +1 表示正 Uq 对应飞轮沿该机体轴正转；-1 表示反转。此方向与自动识别的编码器 `sensor_direction` 不同。`BDIR` 只能改变正负方向，不能纠正轴顺序、非正交安装或 IMU 安装旋转，后者需先核实机械/IMU安装；BAXIS只支持正交轴的排列，不能代替任意旋转矩阵。

当前为电压域状态反馈框架，沿用的默认增益没有根据本机质量、惯量、重心和电机参数求解 Riccati 方程，不能直接视为已整定的最优LQR。飞轮反馈系数允许有符号调整；其稳定性需要结合实际动力学确认。软件具备平衡控制流程，实际稳定平衡尚未实机验证。

## 常用协议

每条 ASCII 命令以换行结束；状态由 `$STATE,...#` 回读，遥测为 `$TELE,...#`。

| 命令 | 功能 |
| --- | --- |
| `PING` | 更新心跳，不产生逐条日志应答 |
| `APP 0` / `APP 1` | 调试/工作模式；先清零失能，可复位停机锁存。上位机在自检与平衡启动时自动切换，一般无需手动发送 |
| `DBG 1..3` | 选择自检/对齐轴；清零失能（上位机三轴自检按 `TEST n` 逐轴执行，此命令仅供终端手动使用） |
| `TEST [1..3]` / `ALIGN [1..3]` | 对选中/指定单轴自检与电角度对齐 |
| `MODE 0` / `MODE 1` | 调试开环/闭环；切换时失能 |
| `EN2 1` / `M2 -3.0` | 独立使能/调速M2；M1/M3同理，闭环要求该轴已对齐 |
| `M 10 -10 0` | 分别设置 M1/M2/M3 目标速度，可同时运行 |
| `ACC 400` | 设置速度目标斜率，范围100～1500 rad/s²，失能时生效 |
| `STOP` | 全部失能，清空待执行指令，锁存停机 |
| `PP?` / `PP2 7` | 查询/设置逐轴极对数，修改后该轴需重新对齐 |
| `FREQ 1` / `FREQ?` | 重置/回读各轴采样率、最大采样间隔、读取耗时、错误计数 |
| `FAST 5` / `FAST 0` | 紧凑M1/M3流 / 恢复普通遥测；调试约100Hz，工作模式约50Hz，避免状态帧挤占串口带宽 |
| `PID2?` / `PID2 0.2 1.5 0` | 查询/设置M2速度PID |
| `TF2 0.012` | M2测速低通时间常数，0.001～0.1秒 |
| `BMODE 1..4` | M1/M2/M3边沿或三轴顶点；切换时失能 |
| `CAL_IMU` / `BZERO` | 静止校准/采集当前模式目标重力方向；都不会启动平衡 |
| `BAXIS 1 2 3` | 设置轮轴到IMU X=1/Y=2/Z=3的排列，需实际核实；设置后重新确认BDIR、采集BZERO |
| `BDIR 1 -1 1` | 三个机架安装方向；操作时失能 |
| `BAXIS1 2` / `BDIR1 -1` | 只确认M1对应IMU Y轴/机架方向；不会将未测的M2、M3标记为已确认 |
| `BCAP 10` | 失能时设置自动入位窗口，范围0.5～10°；实际接管需小于配置窗口与3°的较小者并扶稳 |
| `BTRIP 20` | 失能时设置姿态停机阈值，10～60°；默认20°，限位台架可按需设置60°，不取消其他保护；停机阈值不代表能从该倾角恢复 |
| `BREF gx gy gz` | 失能且IMU/轴/方向已确认时恢复此前保存的单位重力参考，避免把重启后的限位端点当作新零点 |
| `BSTART 8` | 边沿模式等待进入已采集的目标窗口，倒计时8秒；离位取消并等待再次入位 |
| `LQR2?` / `LQR2 32 2.4 0.08 0.008` | 当前边沿/顶点参数组的M2增益，顺序为倾角、机体角速度、飞轮速度、飞轮速度积分 |
| `ZERO2 0.3` | 边沿M2的相对目标偏置，单位度；顶点使用BZERO |
| `BU 3` / `U 5` / `L 180` | 平衡输出限压/全局限压/速度上限（可配至360 rad/s；默认180，调速输入仍为±180；限位平衡试验可单独放宽轮速保护） |
| `BAL 1` / `BAL 0` | 显式启动平衡/全部失能 |
| `ENC?` | 失能时回读I2C/正交方法、各轴CPR、原始计数和角度；正交Ready仅代表计数器可用 |
| `STATE?` / `ATT` | 模式、校准、使能、故障、控制倾角与Uq回读 |
| `SENSOR 1` / `SENSOR 2` | 停机后重新初始化主用LSM6DSR/备用MPU6050；原IMU校准失效 |

状态停机码：0正常、1急停、2心跳超时、3驱动故障/使能条件失败、4接收队列溢出、5主循环超过30ms未更新、6电机传感器/非法输出、7持续堵转、8运行中编码器超过5ms未更新。平衡跌倒或IMU保护还会通过 `Bal:4` 表示。

参数、对齐结果、平衡姿态和方向只保存在RAM，掉电后恢复默认。未接入有效相电流反馈，Uq是控制电压而非实测电流；软件保护不能代替驱动器硬件保护或电源限流。

## 简洁实时角度窗口

当前`CubeMX-corner-immediate`固件取消了单点接管后前0.5秒关闭轮速反馈、再渐入到1.5秒的延迟，单点从第一个控制周期即使用完整轮速项。入位、倒计时及交接都要求三只飞轮有效且低于5rad/s；中途转快会返回等待。实际接管前仍需按窗口扶稳，PG6亮即松手。`ACC`只影响电机调速模式，平衡模式直接控制Uq。新的完整反馈行为不代表当前参数已通过长期平衡，需按实机记录使用。

2026-10-16：辅助窗口改为持续运行的只读角度显示，去掉记录候选按钮、绘图和点击后结束采样的流程。只显示当前Pitch/Roll、固定目标、角度偏差和运行状态；无需点击记录或反复确认支点。

从仓库根目录启动：

```powershell
python "无刷闭环联调/Software/pose_monitor.py" --port COM7 --live-file ".codex-debug/20261016-com-validation/live.json" --target-pitch 23.4399 --target-roll 50 --capture-angle 1
```

窗口无采样时限，串口断开会自动重连。角度过期会显示“—”，不会把旧值当实时值。单点试验、自动单点和自检脚本会自动让窗口交出串口，测试期间通过同一个`--live-state`文件显示数据，脚本退出后窗口自行恢复串口读取。窗口不发送任何控制命令或PING，不会启动电机，也不会替代测试进程维持安全心跳。无需再运行`serial_passive_pose.py`给这个窗口供数。固件接管倒计时及跌倒/超速保护仍保留。

有界单点试验的状态行显示剩余运行秒数；退出后保留上次结果，明确区分“定时结束（N秒）”“角速度/倾角/轮速保护停机”和异常停机。缺少新鲜失能确认时显示“停机未确认”，不显示正常定时结束。原始角度仍继续刷新，没有新增按钮或记录步骤。

固定参考的`serial_corner_trial.py --reference-gravity ...`直接加载BREF后由固件等待入位，不再要求先通过手扶姿态采集门槛；仍检查失能、校准、对齐、编码器、低轮速和新鲜遥测。`--wait-seconds`控制失能等待准备的时间（默认180秒，10～600秒），与`--seconds`实际运行时长分开。机体10°/1.5rad/s主机保护在接管后生效，失能等待时允许移动机体靠近目标；固件入位、倒计时、传感器及其他保护均保留。

## 手扶入位与指示灯

本机没有主动起立/刹车机构，需要先手扶到实际支撑棱的平衡点，采集一次BZERO。之后“等待入位，8秒倒计时后启动”按钮只观察这个固定目标，不会跟着每次晃动改变零点。

- PG5：±10°入位后慢闪倒计时，最后1秒快闪；离开窗口时熄灭并返回等待，电机保持失能。
- PG8：窗口内闪烁表示需要靠近或减小晃动；接近目标约±3°且角速度较低时常亮。倒计时末尾需满足该条件至少0.5秒才接管，否则继续等待入位。
- PG6：实际平衡控制正在运行。
- PG7：跌倒/故障停机。实际运行后跌倒锁存，不会自行再启动，需要明确重新启动。

M4对应程序M1，围绕其支撑棱手动倾斜的实测旋转轴为IMU Y，因此本轮使用`BAXIS1 2`。**恢复方向尚未确认**：用户认为反作用太小、线材可能干扰，已撤回先前方向感受，因此历史试验的−1和+1都不能当作已验证安装方向，需物理限位后重新测量。机体姿态来自IMU，飞轮角度来自MT6701，两者不能混为一项“位置”。状态中的AxisMask/DirMask表示指令明确确认过的轴；仅M1确认时均为1，不能据此启动三轴顶点平衡。

扶持试验使用U/BU=1.5V，状态反馈20/1.2/0.02/0（倾角、机体角速度、飞轮速度、飞轮积分），属于初始试验参数，尚未证明自由平衡稳定。跌倒保护同时检查选定边沿倾角和完整重力姿态变化，包含偏离支撑轴方向的跌倒。具体实测与结束状态见 `diagnostics/2026-10-14/边沿平衡试验.md`。

物理限位下可用`BPROBE 2 60`对当前边沿轴输出2V、60ms定时脉冲。必须在工作模式、失能、该轴已对齐、轮轴已确认、IMU校准有效时执行；不要求先猜机架方向。范围为±6V、20～120ms，并且不超过U限压。超过3V且持续超过80ms时属于长脉冲探测，飞轮保护为100rad/s；其他脉冲仍为60rad/s。F4快速电机循环自行结束脉冲并失能，机体相对移动10°/角速度2rad/s/对应飞轮上限以及原有保护仍会提前中止。探测时FAST约100Hz，附带三轴机体角速度；Bal=7表示探测中。此命令用于有物理约束的安装方向识别。

最新构建`CubeMX-edge-handover/CubeMX.hex`加入接管过渡：机体PD立即生效，飞轮反馈延后0.5秒、再用1秒渐入；Angle为有符号倾角。此版本因CH340/ST-LINK断开尚未烧录，不能把它的回归结果当作板上已经实测。板上最后确认仍是上述20°阈值版本。


手扶接管试验：扶在参考附近保持至PG6亮，然后立即完全松手，手留在旁边保护，不要等待电机先把机体托稳。飞轮的机体反作用力矩来自加减速；手扶时反力被手承担，飞轮匀速旋转也不代表仍有恢复力矩。触碰限位、线材承重、手扶回正的记录不能作为自由平衡通过。60°/300rad/s为限位台架试验设置，既不代表恢复范围，也不代表全范围稳定；设备上电默认仍20°/180rad/s。


## 自动单边/单点平衡

日常操作见[单边M1操作步骤](单边M1操作.md)与[三轴单点调试](单点调试.md)。

工作模式中新增“单边/单点平衡检测与自动运行”区域。区域含“加载已验证 M1 配置（失能）”与“加载已验证单点配置（失能）”。单点配置要求三轴自检完成，恢复23.44°/50°固定参考、轴映射2/3/1、方向−1/−1/−1、三轴80/5/−0.030/0、BYAW 3、BTRIM 0、BCAP 0.5、U/BU6V、L330、20°停机和250rad/s满速阈值；M1配置恢复49°参考、M1→IMU Y、BDIR1=−1、80/5/−0.045/0、U/BU6V、L330。两组参考均只适用于已验证的安装。加载成功须收到BREF应答及匹配的新状态帧；超时或错误则停止。加载本身不使能电机。

点击“启动自动单边/单点”后，固件持续检测入位，没有固定运行时长。单边要求当前轴对齐且该轴飞轮低于5rad/s；单点要求三轴全部对齐、传感器有效、总倾角与完整姿态误差均小于配置入位角（单点默认0.5°）、机体角速度低于0.2rad/s且三只飞轮均低于5rad/s。连续稳定1秒后开始倒计时（单点2秒、单边8秒）；离开条件会取消倒计时。PG6亮后立即松手。

超过±20°立即失能并等待下次入位；任一（单点：任一轴）飞轮连续达到满速阈值（默认250rad/s）3秒也失能等待，低于阈值就清零计时。重试至少冷却1秒，且必须等飞轮降到5rad/s以下，再重新满足稳定入位及完整倒计时。超过L330的硬超速、机体角速度/传感器故障、急停和通信超时锁停并退出自动模式，不会自行恢复。上位机保持连接以提供心跳；断开/退出上位机将停止运行。

| 命令 | 行为 |
| --- | --- |
| `BAUTO 1` | 当前模式（边沿或顶点三轴）进入自动检测，倒计时默认单点2秒、单边8秒；自动模式固定20°倾倒保护 |
| `BAUTO 1 3` | 自动检测，改用3秒倒计时（可选2～15秒） |
| `BAUTO 0` | 退出自动检测并失能 |
| `BFULL 250` | 失能时设置持续满速阈值，10rad/s以上且必须低于L；持续时间固定3秒 |

STATE新增Auto、BReason、FullSpeed、FullMs、RetryMs、EdgeReady、Wheel、Rate。BReason：0无、1倾角、2满速3秒、3硬超速、4机体角速度、5传感器/安全故障。Wheel在单点模式回读三轴最大绝对转速。上位机显示当前是否入位、飞轮转速、满速计时和保护原因，停止自动与急停始终可用。边沿模式只要求当前轴对齐；顶点模式要求三轴全部对齐且固件报告CornerStart=1。长篇无人值守测试使用`diagnostics/serial_corner_auto.py`（无固定时长、自动记录每次尝试与重入、退出必STOP）。

可选命令行：`python main.py --port COM9 --auto-m1`，连接后在已对齐/校准前提下加载M1配置并启用自动检测；前提不满足则保持失能。`--state-json 路径`可保存最新状态用于调试。普通双击启动仍由用户选择连接与启动按钮，不会开机自动转动。


界面操作修复：所有QComboBox统一禁用滚轮改值，获得焦点时也不切换；点击选择仍有效。单边面板在调试和工作模式均可见，加入M1硬件自检与静止校准入口，以及配置/启动禁用原因。完成准备后加载配置与自动启动按顺序解锁。串口连接后同步下拉框到实际连接端口。
