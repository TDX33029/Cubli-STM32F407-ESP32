# 单边 M1 自动平衡操作

M4（用户称呼）就是程序里的M1。所有下拉选择框均已禁用鼠标滚轮改值，点击展开后选择仍可使用。

在同一个“单边平衡检测与自动运行”面板内按顺序操作，不必来回切换模式：

1. 连接COM9、115200，点击“打开串口”。
2. 点击“三轴自检/对齐”（平衡面板中；自检卡片中的“开始三轴自检/对齐”等效），上位机自动依次检测 M1→M2→M3，电机会短时转动；三轴通过后保持失能。已自检通过时可跳过。
3. 让机体静止，点击“静止校准IMU”，保持不动直到完成。已校准时可跳过。
4. 点击“加载已验证M1配置（失能）”，等状态栏提示配置已回读确认。这会切到工作/边沿M1模式，恢复M1→IMU Y、方向−1、49°参考、80/5/−0.045/0、6V、330rad/s硬上限、20°倾倒保护及250rad/s满速阈值，电机保持失能。
5. 点击“启动自动单边（无固定时长）”。扶到参考附近，稳定入位后PG5开始8秒倒计时；PG6亮就立即完全松手。
6. 结束时点击“停止自动单边并失能”；“紧急停止”随时可用。

按钮灰色时，查看面板里的“配置准备”和“自动启动”两行提示。它会说明需要连接、自检、静止校准、加载参考还是先停止现有控制；两个准备按钮始终在该面板可见。

运行中超过±20°，或连续达到250rad/s超过3秒，会失能等待；飞轮低于5rad/s且重新稳定入位后再倒计时。急停、断连或硬故障会退出自动模式。上位机需保持连接。

日常测试可直接加载验证配置。修改轮轴映射会清空平衡参考，重新加载配置可恢复。掉电/复位后需要重新自检和校准；机械安装或支撑棱改变后需重新验证参考姿态。
