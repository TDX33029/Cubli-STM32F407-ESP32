## Introduction

All 3D and 2D resources used in the project, including both test structural parts and formal structural parts.

## Directory Structure

| Directory | Contents |
| --- | --- |
| `3D/` | Main frame, mainboard support bracket, flange, and other main structural files drawn in SolidWorks, as well as Zhubang simulation 3D files and the assembly |
| `2D/` | Momentum wheel flywheel AutoCAD files and ordering parameters |
| `STL/` | Slice files ready for direct use with 3D printers, containing all necessary structures. The printer should be configured with a 0.2 mm hardened steel nozzle and PLA material. The print parameters are 0.08 mm High Quality @BBL A1 0.2 nozzle |
